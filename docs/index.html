An electronics store that speaks two languages متجر إلكترونيات يتحدث لغتين

Borcelle is a full storefront built with React: browse products, fill a cart, log in with a phone code, and pay. Every product, cart and order comes from a live API. بورسيل متجر إلكتروني كامل مبني بمكتبة React: تتصفح المنتجات، تملأ السلة، تسجّل الدخول برمز يصل إلى هاتفك، ثم تدفع. كل المنتجات والسلال والطلبات تأتي من خادم حقيقي.

The shopper's pathرحلة المتسوق

From the first click to a placed orderمن أول نقرة حتى تأكيد الطلب

  1. Browseالتصفح

    Categories, deals and products load from the API on the home page.الأقسام والعروض والمنتجات تُحمَّل من الخادم في الصفحة الرئيسية.

  2. Product pageصفحة المنتج

    Photos, price, a specs table and a feature list in both languages.الصور والسعر وجدول المواصفات وقائمة الميزات باللغتين.

  3. Cartالسلة

    A guest cart that works without an account, plus a quick bag in the navbar.سلة للزائر تعمل بدون حساب، مع حقيبة سريعة في الشريط العلوي.

  4. Phone loginالدخول بالهاتف

    Enter a number, then the one-time code. New numbers are registered on the spot.أدخل رقمك ثم الرمز المؤقت. الرقم الجديد يُسجَّل تلقائياً.

  5. Address & payالعنوان والدفع

    Save an address and pay by cash, Syriatel or MTN.احفظ عنوانك وادفع نقداً أو عبر سيرياتيل أو إم تي إن.

  6. Ordersالطلبات

    Every placed order appears in the order history.كل طلب يظهر في سجل الطلبات.

The parts you don't seeالأجزاء التي لا تظهر للمستخدم

Accept-Language

Live API in the right languageخادم حقيقي باللغة المناسبة

Each request tells the server which language is active, so product and category names come back translated.كل طلب يخبر الخادم باللغة الحالية، فتصل أسماء المنتجات والأقسام مترجمة.

cache · 60s

Catalog cacheذاكرة مؤقتة للمنتجات

The same catalog request within a minute is answered from memory, kept separately for each language.إذا تكرر نفس الطلب خلال دقيقة، يُجاب من الذاكرة، مع نسخة منفصلة لكل لغة.

guest → account

Cart that follows youسلة تنتقل معك

Items added as a guest are moved into your account cart as soon as you log in.المنتجات التي تضيفها كزائر تنتقل إلى سلة حسابك فور تسجيل الدخول.

rollback

Safe quantity changesتعديل آمن للكميات

If the server rejects a quantity change, the cart line goes back to its last good value.إذا رفض الخادم تعديل الكمية، يعود المنتج في السلة إلى قيمته السابقة.

code 11111

Demo modeوضع تجريبي

Reviewers can try checkout without a real SMS. Demo data stays in the browser.يمكن تجربة الشراء بدون رسالة حقيقية، وتبقى البيانات التجريبية في المتصفح.

curated catalog

Clean shelvesرفوف مرتبة

Test categories and products on the shared training server are hidden by ID, including direct product links.الأقسام والمنتجات التجريبية على خادم التدريب المشترك مخفية برقمها، حتى عند فتح رابط المنتج مباشرة.
